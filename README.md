# Catálogo Digital Interactivo Aura

Catálogo web de fragancias inspirado en alta perfumería, optimizado para navegación en dispositivos móviles y computadores de escritorio, con checkout directo vía WhatsApp.

## ✨ Características

- 📱 **Mobile-First & Responsive**: Experiencia visual tipo app en celulares y adaptada a pantallas de escritorio.
- 🖤 **Estética de Lujo Aura**: Paleta en negro obsidiana y toques de oro champaña acorde a la identidad de marca oficial.
- 💎 **59 Fragancias de Alta Gama**: Fotografías completas extraídas sin recortes, filtradas por Dama y Caballero con sus familias olfativas (Dulce, Floral, Cítrica, Amaderada, Oriental, Frutal, etc.).
- 🛍️ **Presentaciones Multi-Tamaño**:
  - **10ml**: $10.000
  - **30ml**: $22.000
  - **50ml**: $35.000 *(Presentación Más Vendida)*
  - **100ml**: $50.000
- 🛒 **Carrito de Compras y Pedido Directo**: Los clientes pueden pedir directamente una fragancia o acumular varios perfumes en el carrito y enviar el pedido consolidado a WhatsApp (+57 313 296 0576).
- ⚙️ **Panel de Administración (`admin.html`)**: Interfaz para consultar, filtrar y registrar nuevas fragancias con descarga de datos actualizada.

## 🚀 Despliegue en GitHub Pages

Para publicar este catálogo de manera gratuita y accesible para todos los clientes:
1. Subir este repositorio a GitHub.
2. Ir a **Settings** > **Pages**.
3. En **Branch**, seleccionar `main` y la carpeta `/ (root)`.
4. Hacer clic en **Save**. En un par de minutos estará disponible en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.
